University project / Project case study

Weather Forecasting & Data Pipelines

Turning source data into interpretable forecasts

01 / The problem

Forecasting involves preparing reliable inputs and communicating the limits of predictive output. This project explored historical and real-time weather data processing.

02 / My approach

  1. Prepared weather information using a structured ETL and data-cleaning process.
  2. Explored forecasting approaches including ARIMA and Random Forest.
  3. Visualised outputs in Power BI for easier interpretation.

03 / Tools & methods

PythonARIMARandom Forestscikit-learnPower BI

04 / Systems Analyst perspective

Data-flow mapping, validation of input quality, assumptions, output communication and analytical system limitations.

Evidence note: This was a university project. Real-time production operation and forecasting accuracy metrics have not been independently verified.
