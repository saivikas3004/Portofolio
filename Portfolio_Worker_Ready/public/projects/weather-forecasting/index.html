Project overview

Project context & objective

This university project examined weather forecasting as an end-to-end information workflow: ingesting observations, preparing them for analysis, exploring forecasting approaches and presenting outputs to users.

Forecasting involves preparing reliable inputs and communicating the limits of predictive output. This project explored historical and real-time weather data processing.

Weather observations are time-dependent, and reliable forecasts rely on consistent inputs. Data arriving from different periods or sources must be organised so time-series and machine-learning methods can interpret the information correctly.

Methodology

From inputs to insights

The following stages explain the workflow and the technical decisions behind this project.

01

Weather-data preparation

The project used historical and real-time weather information in an ETL-style process, organising observations before analysis and model exploration.

02

Statistical forecasting

ARIMA was one of the forecasting approaches explored. It provides a time-series perspective on patterns in historical observations.

03

Machine-learning exploration

Random Forest and scikit-learn were also part of the project toolkit, representing an alternative supervised modelling approach.

04

Communicating forecasts

Power BI was used to visualise forecasting outputs. Presenting results is important because an analytical prediction must be understandable to users beyond the developer.
